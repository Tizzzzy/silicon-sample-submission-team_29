# Tier-2 Direct Group-Level Predictions for Silicon Sample Benchmark

This directory contains code and documentation for generating Tier-2 submissions using **direct group-level prompting** — a fundamentally different method from Tier-1 individual simulation.

## Quick Start

```bash
# 1. Self-test the questionnaire parser (no GPU needed)
python ../LLM_simulation/questionnaire_parser.py

# 2. Preview prompts without GPU
python generate_tier2_direct.py --dry_run

# 3. Smoke test (2 conditions, no retries)
python generate_tier2_direct.py --conditions_subset control,Consensus --max_retries 0

# 4. Full run
python generate_tier2_direct.py

# 5. Register and validate
Rscript ../scripts/manifest.R && make check
```

## Design Rationale: Direct Group-Level Prompting

### The Trade-off

**Tier-1 approach (individual simulation):**
- Simulate 9,000 synthetic respondents with demographic profiles
- Prompt LLM once per person
- Aggregate to cell means
- Preserves distributional shape (variance, quantiles)
- Cost: ~9,000 LLM calls

**Tier-2 direct approach (this implementation):**
- Prompt LLM once per (condition) cell → 17 main cells
- Prompt LLM once per (condition × moderator × level) cell → 459 moderator cells
- Total: **476 LLM calls** (52× cheaper than Tier-1)
- Ask the model to directly estimate the **group average** response
- Cost: ~476 LLM calls, ~1 hour GPU time
- Loss: No distributional information (only cell means, no variance)
- Gain: Deterministic (temperature=0.0), reproducible, fast

### Why This Works

The core assumption: **An LLM can estimate group-level opinions by directly reasoning about demographics.**

Instead of simulating thousands of individuals, we ask the model: "If you surveyed many U.S. Democrats on climate trust, what would the average response be?" This is a legitimate alternative to the sampling-based approach, with different computational characteristics and trade-offs.

This becomes an independent **secondary entry** (team_29, secondary-1), distinct from the primary Tier-1 entry. Organizers do not double-count; secondary entries are explicitly for methodological diversity.

## Key Prompt Differences from Tier-1

| Aspect | Tier-1 | Tier-2 |
|--------|--------|--------|
| **Opening** | "You are a survey respondent with characteristics: ..." (individual persona) | "You are simulating the AVERAGE response of {population}" (group average) |
| **Task framing** | Answer all 44 items as yourself | Estimate the average response if we surveyed many people in this group |
| **Item 44 (newsletter)** | "Would you subscribe? (0 or 1)" | "What PROPORTION would subscribe? (0.00-1.00 decimal)" |
| **RESPONSE_FORMAT newsletter line** | `[0 or 1]` | `[0.00-1.00 proportion]` |
| **Temperature** | 0.7 (sampling diversity) | 0.0 (deterministic, central-tendency) |
| **# of LLM calls** | ~9,000 (one per synthetic respondent) | ~476 (one per cell) |

---

## The `newsletter_signup` Proportion Framing

In Tier-1, respondents make a binary choice: subscribe (1) or don't (0).

In Tier-2, we ask: **What proportion of the group would choose to subscribe?** This is conceptually the group average of the 0/1 Tier-1 choices, but we ask for it directly as a decimal (0.0–1.0) rather than simulating 1,000s of individual binary choices and aggregating.

**Example:** If you estimate that 35% of Democrats would subscribe to the climate newsletter, you report `0.35` (not 35, not a yes/no).

This framing is:
- **Semantically correct:** The Tier-2 value is the expected value of a Bernoulli draw from the group.
- **Practically clearer:** The LLM directly estimates a rate, not an individual binary choice.
- **Validation-friendly:** SCALE_RANGES already enforces (0, 1) bounds; no code changes needed, only prompt wording.

## Default Policies and CLI Overrides

Four design choices have sensible defaults. All are overridable via CLI flags:

### 1. Control Stimulus Text (3 variants available)

The questionnaire has 3 control filler texts: "neckties", "baseball", "dances".

**Default:** Filler text #1 (neckties)  
**Why:** Arbitrarily chosen; all 3 are short, semantically neutral fillers on unrelated topics.  
**Override:** `--control_filler_index 1|2|3`

### 2. Extreme Weather Predictions (state-adaptive, 4 case variants)

This intervention is adaptive: respondents see different stimulus text based on their home state. The questionnaire includes 4 case texts for states outside 3 specific groups.

**Default:** Case 4 (the generic/fallback case)  
**Why:** Since Tier-2 group-level prompts have no state field, Case 4 is the most neutral option.  
**Override:** `--extreme_weather_case 1|2|3|4`

### 3. Consensus Stimulus (interactive quiz → passage)

The Consensus condition is an interactive quiz (respondents estimate percentages, see corrections, get feedback). For Tier-2's text-only framing, we use only the intro and closing summary paragraphs, dropping the quiz mechanics.

**Default:** Intro paragraph + Summary paragraph  
**Why:** Captures the main persuasive intent without the interactive mechanics that don't translate to group-level prompting.  
**(No override needed; hardcoded in questionnaire_parser.py)**

### 4. Sampling Temperature

Controls randomness in LLM output.

**Default:** 0.0 (fully deterministic/greedy)  
**Why:** Tier-2 is about estimating central tendency (the group mean), not sampling diversity. Temperature 0.0 is reproducible and defensible for this task. Differs from Tier-1 (0.7) because the task is different.  
**Override:** `--temperature 0.0|0.5|1.0|...`

## Advanced Options

### Parallel GPU Execution

Run on multiple GPUs:

```bash
python generate_tier2_direct.py \
  --tensor_parallel_size 4 \
  --batch_size 64
```

### Custom Model Path

```bash
python generate_tier2_direct.py \
  --model_path /path/to/another/model
```

### Resume from Checkpoint

The script writes a jsonl log of all LLM outputs. To resume a failed run:

```bash
# After fixing an error, re-run with the same random seed
python generate_tier2_direct.py \
  --seed 2026 \
  --version 2
```

(Outputs go to `v2` filenames.)

### Testing with Smaller Sample

```bash
python generate_tier2_direct.py \
  --max_cells 50 \
  --max_retries 0
```

Processes only the first 50 cells, useful for quick validation of prompt quality before a full run.

```bash
python ../LLM_simulation/questionnaire_parser.py
```
Should print "OK Extreme weather predictions".

```bash
tail -100 raw_data_deposit/generate_tier2_direct_*.log | grep -A2 "parse failed"
```
May indicate the LLM output format has drifted from expected regex pattern.

## Design Notes and Assumptions

### Domain Transfer: Partisan Policy → Climate Trust

This benchmark focuses on **climate scientist trust** (Tappin et al. adapted for climate domain). The Tier-2 direct-prompting method makes no special assumptions about the domain — it asks the LLM to reason about group demographics and opinion in general terms. This is a **proof-of-concept** that the method works across domains; your professor should confirm whether the domain transfer (persuasion → climate) is acceptable for your use case.

### No Distributional Information

Tier-1 preserves the **full distribution** of individual responses (mean, variance, quantiles) by simulating many respondents and aggregating. Tier-2 gives only the **mean** for each cell. If your analysis requires variance, inter-quartile ranges, or other distributional properties, Tier-1 is the appropriate choice.

### Deterministic (temperature=0.0)

Unlike Tier-1's temperature=0.7 (random sampling for diversity), Tier-2 uses temperature=0.0 (greedy/deterministic). This means:
- **Reproducible:** Same prompt always yields the same LLM response
- **No variance from randomness:** The "randomness" in Tier-2 results comes from group heterogeneity (different moderator levels), not sampling variance
- **Appropriate for central tendency:** Estimating a group mean doesn't require exploring the LLM's sampling distribution

## Summary

**Tier-2 direct group-level prompting** is a fundamentally different method from Tier-1 individual simulation:
- **Cost:** 476 LLM calls vs. 9,000 (52× cheaper)
- **Task:** Ask the LLM directly to estimate group averages, rather than simulating individuals
- **Output:** Per-cell means (no distributional info)
- **Temperature:** 0.0 (deterministic) vs. 0.7 (sampling)
- **Trade-off:** Faster and cheaper, but no variance / quantile estimates

The code handles all benchmark requirements (17 conditions, 13 outcomes, 6 moderators, 27 levels) and produces submission-ready CSVs. Default policies (control filler #1, Extreme weather Case 4, Consensus intro+Summary, temperature 0.0) are all documented and overridable.

Run `python generate_tier2_direct.py --dry_run` to preview prompts, then follow the instructions above for a full submission.
